# IMDB Movie Review Sentiment Analysis using LSTM

## Overview

This project performs sentiment analysis on movie reviews from the IMDB dataset using a Long Short-Term Memory (LSTM) deep learning model built with TensorFlow and Keras.

The model classifies reviews as:

* Positive 😊
* Negative 😞

## Features

* Data preprocessing and cleaning
* Text tokenization
* Sequence padding
* LSTM-based deep learning architecture
* Model evaluation on test data
* Real-time sentiment prediction from user input
* Model saving for future use

## Technologies Used

* Python
* TensorFlow / Keras
* Pandas
* NumPy
* Scikit-Learn

## Dataset

IMDB Movie Reviews Dataset

Dataset contains 50,000 movie reviews labeled as:

* Positive
* Negative

## Model Architecture

1. Embedding Layer
2. LSTM Layer (128 Units)
3. Dense Layer (64 Units)
4. Dropout Layer
5. Output Layer (Sigmoid Activation)
